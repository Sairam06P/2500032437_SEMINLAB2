# Experiment 05 – Alert Box

## Project Description
This project demonstrates a reusable Alert Box component using React JS.

It displays two types of alerts:
- **Success Alert:** Displays a green success message.
- **Error Alert:** Displays a red error message.

## Technologies Used
- React JS
- JavaScript
- CSS
- HTML

## Installation

Install the dependencies:

```bash
npm install
```

## Run the Project

```bash
npm start
```

Open http://localhost:3000 in your browser.

## Features
- Reusable Alert Box component.
- Success and Error message display.
- Different background colors for alerts.
- Simple and clean React application.
